I am creating a saas application which will be a hair booking platform that salons can onboard onto and manage their shop on, also clients will be able to pick a service, then pick a salon near them. The website should enable clients to:

- book appointments (& pay a deposit at the point of booking)
- customise their service (e.g. style, colour, length) with a dynamically updating visual preview (updated every time a new length/colour etc. is chosen)

This should be a scaleable platform that starts with one stylist but will grow to a platform that has hundreds of stylists using this platform. The tech needs to be modern & up to date, adhering to the best coding practices.

More context on this project:
At the moment this project is only front-end but my plan is to build a scaleable backend to create a working app, then lastly completely revamp the front-end to a more polished look. So this project is to get started on the backend to make the website functional, my current steps are:

- refactor code of the git repo & make it adhere to best practices, remove unused code etc. (done)
- switch to use React & Typescript (done)
- start on the backend: create an express server, create a login system & onboarding process for hairstylists etc.
